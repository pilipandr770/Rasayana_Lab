Протокол докінгу провалідовано. Узяли відомий ліганд із незалежної структури, побудували для нього новий 3D-конформер «наосліп» (наче не знаємо відповіді) і задокували заново. Результат відтворив реальну кристалографічну позу з точністю 0.37 Å — це на рівні еталонних бенчмарків у галузі, підтверджує, що наш пайплайн знаходить фізично правильні пози зв'язування, а не випадкові. The docking protocol has been validated. We took a known ligand from an independent structure, built a fresh 3D conformer for it "blind" (as if we didn't know the answer), and redocked it. The result reproduced the real crystallographic pose to within 0.37 Å — benchmark-grade accuracy, confirming our pipeline finds physically correct binding poses, not random ones. Das Docking-Protokoll wurde validiert. Wir haben einen bekannten Liganden aus einer unabhängigen Struktur genommen, dafür „blind" (als kennten wir die Antwort nicht) einen neuen 3D-Konformer erzeugt und ihn neu andocken lassen. Das Ergebnis reproduzierte die reale kristallographische Pose mit einer Genauigkeit von 0,37 Å — Benchmark-Niveau, das bestätigt, dass unsere Pipeline physikalisch korrekte Bindungsposen findet, keine zufälligen.
